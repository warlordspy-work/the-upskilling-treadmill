Concept Check • Kubernetes Pod Eviction

Which Kubernetes resource limit directly causes an OOMKilled (Exit Code 137) container status when exceeded?

pod-spec.yaml YAML 
resources:
  limits:
    memory: "512Mi"
    cpu: "500m"
verified

Correct!

When a container exceeds its memory limit, the Linux kernel OOM-killer terminates the process with exit code 137. Unlike CPU limits which simply throttle execution cycles, exceeding memory is an unrecoverable hard violation.

terminal kubectl describe pod → Last State: Terminated (Reason: OOMKilled)
